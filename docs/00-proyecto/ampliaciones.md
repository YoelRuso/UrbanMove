# Ampliaciones valorables

- [ ] Autenticación y roles separados para usuarios y mantenimiento.
- [ ] Uso de Terraform para recursos cloud.
- [ ] Despliegue de contenedores en ECS y publicación de imágenes en ECR.
- [ ] Uso de S3, DynamoDB, SQS, SNS, EventBridge, Lambda y CloudWatch.
- [ ] Contratos OpenAPI y AsyncAPI versionados para microservicios y eventos.
